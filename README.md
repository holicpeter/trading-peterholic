# Trading Dashboard - trading.peterholic.com

Sumár a stav 5 trading robotov pre Peter Holic.

## Deployment na GitHub Pages

1. Repo je nastavené pre GitHub Pages (main branch / root alebo /docs).
2. V DNS u registrátora domény peterholic.com pridaj CNAME záznam:
   - Host: `trading`
   - Points to: `holicpeter.github.io` (alebo podľa GitHub Pages URL)

Po propagácii DNS bude stránka dostupná na https://trading.peterholic.com

Hlavná doména peterholic.com zostáva nezmenená.
